## 🌐 How to Deploy Free (in 60 seconds)

### Option 1: Vercel (Instant)
1. Go to [vercel.com](https://vercel.com)
2. Drag and drop the `supernova-portfolio` folder.
3. Your live link (`supernova-saran.vercel.app`) is active immediately!

### Option 2: GitHub Pages (Free forever)
1. Push this folder to a GitHub repository `supernova-portfolio`.
2. In Settings ➔ Pages, choose `main` branch.
3. Your site is live!
